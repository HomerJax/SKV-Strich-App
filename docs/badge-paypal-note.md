# Badge / PayPal Ideen-Merker

## PayPal / Mannschaftskasse

Für die Mannschaftskasse ist zunächst **keine tiefe PayPal-API-Integration nötig**.

Gewünschter pragmatischer Ansatz:
- Club kann einen bestehenden **PayPal-Pool / Zahlungslink** hinterlegen.
- strikr zeigt daraus einen **klickbaren Link** und optional einen **QR-Code** an.
- Die eigentliche Zahlung läuft direkt über PayPal.
- Status / Buchungen in strikr können zunächst manuell gepflegt werden.

## Fokus aktuell

Erst **Badges + Hall of Fame finalisieren**. Danach 3. Halbzeit / Mannschaftskasse / PayPal-Link.
